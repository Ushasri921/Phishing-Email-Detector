# Phishing Email Detector

## About the Project
This project is developed using Python to identify potentially suspicious emails by checking for predefined phishing-related keywords.

## Technologies Used
- Python 3
- Socket-free string processing
- Conditional statements
- Loops

## Features
- Checks email messages for suspicious keywords.
- Classifies messages as phishing or safe based on keyword matching.
- Displays the classification in the terminal.
- Uses sample email messages for testing.

## Keywords Used
- Won
- Free
- Bank
- Blocked
- Password
- Urgent

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Execute the command:

   `python phishing_detector.py`

5. Check the results displayed in the terminal.

## Sample Output
```text
PHISHING EMAIL: Congratulations! You won a free iPhone
PHISHING EMAIL: Your bank account has been blocked
SAFE EMAIL: Meeting scheduled at 5 PM
PHISHING EMAIL: Update your password immediately
```

## Learning Outcomes
- Practiced Python loops and conditional statements.
- Learned string searching and keyword matching.
- Understood basic phishing detection concepts.

## Limitations
This project uses predefined keywords and may incorrectly classify emails. It is a basic educational project and should not be used as a complete email security solution.
